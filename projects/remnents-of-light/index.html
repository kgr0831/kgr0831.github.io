Remnents of Light

원격 에이전트 루프로 만든 2D 액션 게임

개발 노트북이 한 대뿐이라 밖에서는 떠오른 수정을 시험할 수 없었습니다. Discord로 명령을 보내면 에이전트가 고치고 실행해 결과를 돌려주는 개발 루프를 만들었습니다.

기간
2026.07 – 09
역할
전투·연출·원격 개발 도구 · 맵 제작에 팀원 참여
기술
Unity 6 · Discord · Claude Code · Gemini · Unity MCP
결과
첫 스테이지 데모와 10분 분량의 플레이 영상

  • 플레이 영상www.youtube.com/watch?v=WHP7L8P5Be8
  • 소개 페이지kgr0831.itch.io/remnents-of-light

밖에서 명령하면
고치고 실행해 결과를 돌려줍니다

노트북은 꺼질 수 있어서 명령을 받는 봇은 항상 켜진 서버에 두고 실제로 실행하는 프로그램만 노트북에 뒀습니다.

에이전트에게 맡길 일과
사람이 승인할 일을 나눴습니다

노트북 앞에 아무도 없어도 돌아가는 도구라 명령마다 쓸 수 있는 권한을 다르게 줬습니다. 되돌리기 어려운 작업은 멈추고 번호가 붙은 선택지로 묻습니다.

원격 루프를 직접 돌리며
멈추고 새는 곳을 고쳤습니다

명령은 Discord에서 중계 봇과 실행기를 거쳐 Claude Code 호출로 이어집니다. 다섯 문제 가운데 넷이 노트북의 실행기에서 생겼습니다.

검사를 통과한 뒤에도
직접 플레이로 판단했습니다

자동 검사는 수치와 상태를 알려 주고 손에 닿는 느낌은 사람이 판단하도록 역할을 나눴습니다.
