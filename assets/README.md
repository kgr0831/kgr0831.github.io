# 이미지와 로고 출처

이 폴더의 이미지 45개는 `portfolio/portfolio-ax-game/assets/`에서 원본 그대로 복사했습니다. 사용자 제공 `Garam_Kim_Portfolio_Editable.pdf`와 같은 자료이며, 개별 출처는 원본 폴더의 `SOURCES.md`를 따릅니다. 파일 이름과 원본 비율을 보존하고 화면 배치만 CSS로 조정합니다.

- `icons/`: 학교·회사·프로젝트·개발 도구·연락처 로고
- `ui/`: 원본 PDF의 기능 설명용 SVG 아이콘. 로고가 없는 프로젝트의 기능을 표현하는 데 사용합니다.
- EUM, 두드리, 겜마루: 제공된 실제 서비스 화면
- `rol-poster.jpg`: 게임 플레이 영상의 썸네일. 실제 영상은 프로젝트의 플레이 영상 링크에서 확인합니다.
- ROLAI Discord·테스트 씬·구성도: 제공된 개발·검증 자료
- `dudri-award.jpg`: 2026 KOSSCCHTHON 수상 사진
- `paperbridge-reader.png`: 샘플 문서로 기능을 확인한 리더 화면
- `planet-concept.jpg`: 초기 행성·UI 콘셉트 스케치
- `vfriend-*.png`: 캐릭터 프로토타입 일러스트. LoRA 학습 결과나 완성된 서비스 화면으로 표시하지 않습니다.

홈페이지의 이미지 카드, 기관 패널, 기술 로고, 프로젝트 상세창에서 사용합니다. 상세창 이미지에는 한·영 설명을 붙였으며 원본 이미지를 새 탭에서 열 수 있습니다.
